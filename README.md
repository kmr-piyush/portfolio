# Piyush Portfolio Source

This folder contains the complete static source for the portfolio, including the three certificate images linked from the Certifications section.

## Files

- `index.html` — portfolio page and certificate image links
- `style.css` — page styles, including certificate image previews
- `profile.png` — profile image used in the hero section
- `Digital Mrketing.jpg` — Digital Marketing with AI certificate
- `Click2Commerce.jpg` — Click to Commerce certificate
- `TCSiON certificate.jpg` — AI and Cybersecurity Awareness certificate

## View locally

Keep all files in the same folder and open `index.html` in a modern web browser. Selecting a certificate preview opens its full image in a new tab. The stylesheet loads the DM Sans and Space Grotesk fonts from Google Fonts when an internet connection is available; system fallbacks are used otherwise.

## Publish

Upload the files together to your static website host. Preserve the exact image filenames, including spaces, so the certificate links continue to work.
