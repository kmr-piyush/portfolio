# Piyush Portfolio Source

Complete static source for the portfolio, including the certificate image links and the Mini Project II report link.

## Files

- `index.html` — portfolio page and project/certificate links
- `style.css` — page styles
- `profile.png` — profile image
- `Digital Mrketing.jpg` — Digital Marketing with AI certificate
- `Click2Commerce.jpg` — Click to Commerce certificate
- `TCSiON certificate.jpg` — AI and Cybersecurity Awareness certificate
- `Mini Project -2 Final (Piyush).pdf` — Mini Project II report linked under the Smart Noise Canceling Window project

## View locally

Keep all files in the same folder and open `index.html` in a modern web browser. The project link opens the report in a new tab, and certificate previews open their corresponding image files.

## Publish

Upload all files together to your static website host. Preserve the exact image and PDF filenames so the links continue to work.


## Visual effects

The stylesheet adds translucent glass-style cards, soft entrance animations, a gently moving hero glow, and scroll-triggered section reveals in browsers that support scroll-driven animations. Motion is reduced automatically when the visitor has enabled reduced motion in their device settings.


Navigation uses a floating glass pill with animated hover and focus states. The mobile menu also animates in when opened.


The navigation glass has a brighter reflective sheen, luminous inner rim, and a slow animated highlight.


Contact details use matching glass cards with a reflective hover sweep, soft glow, and staggered scroll reveal where supported.


Hero buttons use glossy glass gradients, reflective borders, entrance motion, and lift/press feedback on interaction.
